# 💫 About Me

Начинающий разработчик с **5 годами опыта в программировании**.<br>
Разрабатываю backend-сервисы, Telegram-ботов и мобильные приложения.<br>
Работаю с **Python, Kotlin и Dart**.<br>
Основные направления: **FastAPI, Django, Flutter и Jetpack Compose**.<br>
Использую **Linux** как основную среду разработки и активно работаю с Docker, PostgreSQL и серверной инфраструктурой.
